# IRISMusic 设计风格

> 可直接喂给设计 / AI 复现本 App 视觉语言的风格描述。

## 一句话定位

深色优先的**音乐播放器**：以模糊专辑封面为底，半透明玻璃卡片叠在上面承载内容，高饱和霓虹色作点缀，果冻弹性动效贯穿交互。

## 1. 配色

- **三套正交维度**（互不耦合，任意组合）：
  - 配色主题 `IrisTheme`：8 套——黑白 MONO / 霓虹青 CYAN / 霓虹粉 MAGENTA / 落日橙 SUNSET / 极光紫 VIOLET / 深海蓝 OCEAN / 血红 BLOOD / 青草绿 GRASS。每套是**一对** 主色 + 辅色（primary / secondary）。
  - 明暗模式 `IrisMode`：深色 / 浅色 / 自动。深色背景纯黑 `#000000`、表面 `#111`、卡片 `#1A1A1A`；浅色背景 `#F5F5F7`。
  - 表面材质 `IrisSurfaceStyle`：实色 / 毛玻璃 / 液态玻璃。
- **霓虹色板**（高饱和荧光）：青 `#00F0FF`、品红 `#FF2E97`、紫 `#9D4EDD`、黄 `#FFE94E`、青柠 `#B4FF39`、橙 `#FF8A3C`、红 `#FF4D6D`、蓝 `#3D7BFF`、绿 `#2EE6A8`、粉 `#FF7EB6`。
- 黑白主题主色随明暗反色（深底 = 白、浅底 = 黑）。霓虹色落到浅卡上用 **WCAG 可读性自动压暗**（对比度 < 4.5 时逐步调整至达标）。

## 2. 材质 / 玻璃（核心特色）

- **液态玻璃**：真·折射光学，非画渐变糊弄。效果链 = `调色(提对比 / 饱和，保住封面颜色) → 高斯模糊 → AGSL SDF 位移取样折射 → 镜面内缘高光`。
- **五级厚度**：弹层 SHEET > 播放器 PLAYER > 卡片 CARD > 列表行 ROW > 徽章 CHIP，逐级折射带更窄、模糊更弱、染色更薄（行最薄避免叠成一片白）。
- **不泛白铁律**：深色用近黑烟熏染色而非叠白；要更清晰就提对比 / 饱和，绝不叠白（叠白会冲淡封面颜色 → 玻璃变灰塑料）。
- 染色 alpha 极低（PLAYER 仅 ~0x52），通透靠折射深度与边缘光学，不靠本体白。

## 3. 背景

- 高斯模糊封面铺满：封面压成超小图 + blur 放大，切歌 Crossfade 700ms 交叉淡化（无闪白）。
- 无封面回退**双径向霓虹光晕**（左上青 + 右下品红）。
- 液态玻璃下背景压制更轻（深色 scrim 0.32、实色 0.62），留住颜色供折射取样。模糊半径可调 0–60dp。

## 4. 字体

- **字族可切换**（v4.5.1 起）：
  - 界面字体 `uiFont`：系统（SansSerif）/ 衬线（Noto Serif CJK）。经 `Theme.kt` 的 `LocalTextStyle` 单点下发，全 App UI 文字同步生效。
  - 歌词字体 `lyricFont`：系统 / 衬线，与界面字体各自独立。
  - 歌词字号 `lyricFontSize`：14–32sp 可调（默认 20），作用于全屏歌词所有行含逐字流光。
- **重字重对比**（不随字族改变）：标题 Black / ExtraBold（34 / 22sp，标题负字距 -0.5），正文 Medium 14sp，小标签 Bold 11sp + 正字距 1sp。层级靠字重与字号拉开。
- 另有全局字号缩放 `fontScale`（0.85–1.30），走 `LocalDensity` 注入。
- ⚠️ 不做「等宽 / 无衬线」选项：Android 上 `FontFamily.Monospace` 对中文回退到系统黑体，与 SansSerif 渲染完全相同，是无效摆设。中文只有 Serif 有真实差异。
- ⚠️ 不内置第三方字体：曾试内置霞鹜文楷子集，APK 从 2.4MB 涨到 6.7MB，不划算。只用系统自带字族。

## 5. 圆角 / 形状

- **单一基准 + 比例分级**：基准 `card`（默认 38dp，可调 0–44dp），派生 `sheet` = ×0.74、`item` = ×0.42、`chip` = ×0.26。改一处全局圆润同步。大圆卡、中圆行、小圆徽章层级分明。

## 6. 动效 / 交互手感

- **果冻弹性总开关**驱动全 App：开 = 低阻尼弹簧（按压回弹、拨钮、卡片位移，damping 0.5–0.7）；关 = 平滑 tween / 高阻尼弹簧。
- 统一按压封装 `irisPressable`：按压缩放（主按钮 0.85、通用 0.92）+ 触感 + **无水波**点击（`indication = null`）。
- 弹层统一自底部上滑入场（tween 300, FastOutSlowIn）。主题切换整套配色 450ms 线性插值渐变，不硬闪换色。

## 7. 布局范式

- 四种排布可循环切换：纵向歌单 / 横向卡片轮播 / 堆叠卡片 / 紧凑海报墙（Folia 式整屏网格 + 常驻迷你播放条）。卡片模式下"一首歌 = 一张卡"是核心隐喻。
- 系统栏全透明、内容铺满，图标深浅跟随明暗；关掉系统栏对比度 scrim 实现真透明。

## 8. 设计哲学（提炼）

1. **正交解耦**：配色 / 明暗 / 材质 / 排布 / 圆角 / 模糊浓度各自独立一维，组合而非硬编码。
2. **物理真实优先**：玻璃要真折射取样、缩放要跟手、落盘要像素级重合——宁可上 GPU / AGSL 也不画假的。
3. **可读性兜底**：WCAG 对比度自动校正，黑字在深色封面上也必须压得住。
4. **克制的克制**：状态用灰度 / 透明度表达而非加框加标记；无水波纹；染色不泛白。
