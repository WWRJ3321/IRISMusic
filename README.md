## 功能

| | |
|:--|:--|
| 🖼 **看得见的** | 四种排布：纵向列表、横向卡片、堆叠、唱片墙，排布、配色、明暗、材质互不绑定；实色 / 毛玻璃 / 真折射液态玻璃三种材质；黑白 / 深海蓝 / 青草绿，或用取色方块调出自己的主色与次色；全屏滚动、逐字扫光、悬浮、封面四种歌词。 |
| 🎧 **听得见的** | 自由曲线均衡器，加虚拟低音、宽场环绕、动态范围增强、防失真保护、响度均衡；音律震动跟着底鼓轻轻震，力度随鼓点强弱变化。 |
| 🧠 **看不见的** | 本地推荐按点赞、播放、跳过给整个曲库打分，可调「探索度」；听歌报告统计最常听的歌；默认不联网，只有手动打开「检查更新」时才向 GitHub 发一次请求，不含任何统计。 |

> 唱片墙的交互灵感来自 [Folia](https://github.com/chthollyphile/folia-major)，已获原作者授权，代码为独立实现。

## 安装

在 [Releases](https://github.com/WWRJ3321/IRISMusic/releases/latest) 下载 `IRISMusic-*-arm64-v8a.apk`（近几年的手机基本都是 arm64），直接安装。

首次打开授予「读取音频」权限即可。悬浮歌词需要在系统设置里允许「显示在其他应用上层」。
