# IRIS Music 🎧

**一个本地音乐播放器。** 真·折射液态玻璃，三种排布，可自定义配色，不联网

*做自己想用的播放器*

`Kotlin` · `Jetpack Compose` · `Android 7.0+` · `GPL-3.0`

IRIS Music 是个**个人项目**：没有团队、没有 KPI，也不商业化。它只做我想要的样子——把手机里的音乐用简单卡片铺开，数据全部留在本机

> ⚠️ 请先阅读 [`REMIND.md`](./REMIND.md)（许可与免责声明）。本软件按 **AS IS** 提供，**无任何担保**。

## ✨ 特性

- **各种主题**：黑白、霓虹粉、深海蓝、青草绿三套彩色主题，外加**自定义**——用取色器任意调主色 / 次色，实时生效；再叠加深色 / 浅色 / 自动明暗。
- **本地推荐算法**：大多数本地播放器都没有。基于点赞、播放次数、跳过、风格等加权打分，给整个曲库独立计算推荐度，还能调「探索度」在"投其所好"和"多探索新歌"之间权衡。
- **一库三排**：纵向 / 横向 / 堆叠等排布、配色、明暗、材质各自独立一维，任意组合、不硬编码。
- **它不上网**：清单里没有 `INTERNET` 权限。歌单、收藏、听歌统计全部只留在本机，安全、无广告、无遥测。
- **各种新奇的功能**：低音马达音乐随心跳震动、一年听歌时长热力图报告、频响图上直接拖锚点的均衡器、果冻弹性动效等。

## 📥 安装

去到 [Releases](./releases) 下载 `app-arm64-v8a-release.apk`（绝大多数近几年的手机）。

需要授予「读取音频」权限；若要悬浮歌词，需在系统设置里手动授予「显示在其他应用上层」。
